## About this lab
Binary classification on a synthetic service-ticket dataset. The goal is to predict whether a ticket is escalated (1 = escalated), and to choose metrics and a decision threshold based on the cost of mistakes, not just on accuracy.

## What's inside
- `lab3_ticket_escalation.ipynb`: the completed notebook with outputs, tables, plots and the written recommendation
- `classification_escalation.csv`: the dataset
- `requirements.txt`: the libraries needed to rerun the notebook
